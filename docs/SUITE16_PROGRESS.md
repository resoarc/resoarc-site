# ResoArc 16機能開発状況（2026-10-16）

## 分類と提供範囲
- kintone 8種類: 自動採番、タブ表示、条件付き表示・必須制御、条件付き書式、高機能検索・絞り込み、日付・期間計算、Excel風一覧編集、カード・カンバン表示。
- Web 8種類: 一括更新変更前確認、アプリ設定差分比較、権限定義監査、CSV取込前診断、重複候補検出、ルックアップ不整合診断、アプリ横断集計、ブラウザー帳票/PDF。

## Web 8種類
- 既存: アプリ設定差分比較β、CSV取込前診断β。
- 新規: 一括更新プレビュー、権限定義の可視化、重複候補、ルックアップ診断、統合済データの集計、帳票/ブラウザーPDF。6種はいずれもオフライン解析β版。
- 制約: kintoneへのログイン、変更APIの実行、実効権限の判定、各アプリの自動収集、Excel(.xlsx)読込、ルックアップ修復、一括更新、グラフ描画は未実装。
- 安全: ローカルで処理し、ファイルをサーバーに送らない。帳票はHTMLをエスケープする。

## kintone 8種類
- 自動採番: 通常フィールド版を配布済み。テーブル対応β版は開発済み、実機未検証。
- タブ表示: β版配布済み。実機未検証。
- 条件付き表示・必須制御: α版ソース公開、実機未検証。
- 他5種類: 条件付き書式、日付・期間計算、高機能検索、Excel風一覧編集、カンバン表示。開発α版ソース・単体テストを追加。kintone実機未検証のため署名ZIPは未配布。
- 2026-10-16 追加改善: 高機能検索を最大2,000件までの一覧条件付き読取検索に拡張（既定は現在のページのみ）。最大500件/回のAPIページング、ID順の続き取得、権限に従う参照、途中中止、取得上限の明示に対応。全件検索は未実装。Excel風一覧編集は3種の更新可能なフィールド型に限定し、不正な数値と再送信を防止。ブラウザ上で正常終了・途中失敗を試験。
- 2026-10-16 改善: 5種類のJSON専用設定画面をフォーム化。フィールドコード候補の補完（API取得可能な場合のみ）、複数ルール追加・削除、各コアと共通の保存前検証、旧JSON設定の再読み込みに対応。Playwrightによる5画面操作テストを追加。
- 公開ZIPは署名済みkintoneプラグインではなくソース配布。`python scripts/verify_alpha_archives.py` でZIP内の全ファイルとGitHub公開ソースの一致を検査。

## 受け入れ基準
各機能の単体試験に加え、kintone実機テスト、権限・モバイル・テーブル・競合プラグイン確認、ZIP署名とサンプル導入の検証を実施後に安定版とする。
