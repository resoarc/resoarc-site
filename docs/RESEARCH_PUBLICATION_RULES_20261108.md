# SWWW / TrapNet 公開研究方針（2026-11-08）
## SWWW: 脆弱性天気予報
- データソース、観測時刻、最終更新、取得成否、除外理由、欠測期間を証跡として残す。
- COMPLETE / PARTIAL / UNAVAILABLE 等を定義し、PARTIALを全件調査済みと見なさない。
- 収集範囲と母集団が同等な期間だけ比較する。「危険度予測」と実際の侵害件数を混同しない。
- OSV/CVE等の再配布条件を確認し元情報に辿れるようにする。件数やグラフは実データ照合なしに創作しない。
## TrapNet: 観測・隔離研究
一般公開・共同研究は安全ゲートを満たすまでHOLD。
- 生ログ、IP、認証情報、攻撃ペイロード、個人情報を公開しない。集約・秘匿化後に共有。
- 観測事実、推測、再現実験を区分。通信の存在だけで意図や侵入成功を断定しない。
- ネットワーク非接続性、リソース上限、ログ完全性、権限境界をオフライン再現試験で証明する。
- root-signed配布、独立レビュー、運用分離、復旧、欠測開示が完了するまで自律防御を宣言しない。
- 協力依頼はソースのテスト・文書レビューと安全なオフライン検証に限定。
