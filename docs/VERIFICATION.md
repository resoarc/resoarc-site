# 再現性と検証の手順

## 1. 手元で実行

```bash
python scripts/verify_site.py
python -m http.server 8000 --directory site
```

http://localhost:8000/ にアクセスし、各ページの表示、SHA-256確認ツール、CSV構造検査ツールを操作してください。

## 2. 検証対象

- 構成ファイルの存在、HTML内の内部リンク、必須のアセット
- 外部参照とサードパーティライセンスの記載
- 公開してはいけない文字列が混入していないかの基本的な機械検査
- JavaScript構文のチェック（Node.jsがある場合）

これらのテストは基本的な静的検査です。セキュリティ監査、権利保証、データ取扱い全般の検査を代替しません。

## 3. 公開サイトとの照合

静的な `site/` ディレクトリがソースの正本です。ビルドによる変換工程は必須ではありません。Cloudflare Pagesにアップロードされた内容を確かめる場合は、本番URLから各ファイルをダウンロードし、正本のファイルごとにSHA-256値を比較してください。CDNの圧縮や正規化の影響を避けるため、HTTPの転送表現でなく内容バイト列を比較します。

初回公開の段階では、全公開URLとGitHubコミットの完全一致を**検証済みとは主張しません**。照合実施時に結果と日付を追記します。

## 4. 透明性の範囲

公開されたソフトウェアの中身は第三者が取得できます。Cloudflareの内部インフラ、秘密鍵、利用者のデータ、外部事業者が保持する監査ログは公開対象ではありません。「完全に検証できる」という表現は、**公開ソフトウェアの実装・公開根拠・検証手順**を意味し、あらゆる外部環境の完全可視化を意味しません。
