## 公開禁止の条件

- モックテストのみでは正式版に昇格しない。
- ファイル取得、CSV出力、権限、入力変換、依存API、モバイル適合性は実利用に近い試験で確認する。
- 署名秘密鍵、Cookie、APIトークンをソース/ZIP/ログへ含めない。
- 顧客・本番アプリへ書き込まない。テストアプリだけを使用し、実行IDで作成レコードを厳格管理する。
- 社内・顧客由来コードを混入しない。独自コードで実装し、ライセンスを確認する。
