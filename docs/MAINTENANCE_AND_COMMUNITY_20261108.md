# ResoArc継続運営とコミュニティ方針（2026-11-08）
ResoArcは独立OSS活動であり、公的認証機関・企業・財団ではない。応答SLAはない。
- 技術的変更はGitHub Issue/PRに理由、影響、テスト、ライセンス情報を残す。
- リリース・秘密・著作権・安全ゲートの最終判断は実際の運営責任者が行う。AIの役割分担は独立した人間レビューを意味しない。
- 外部投稿の採否は安全性、品質、ライセンス、維持費で判断する。
- 共同管理者を追加するなら最小権限、実在性確認、緊急失効、引継ぎを整える。
- 脆弱性の非公開報告先はSECURITY.md。公開Issueに秘密を書かない。
- 継続困難時は新規配布停止と最終版の検証済みソース・既知の問題をアーカイブし保守状況を明記。
## 資金調達について
現時点で寄付募集やスポンサー特典、商用サポートを開始したと宣言しない。開始する場合、運営主体、使途、返金、利益相反、第三者権利、会計処理を確定させてから公開。
