# ResoArc Web診断ツール 8機能 v1.0.0 正式リリース

リリース日：2026-10-16

## 対象と区別

この正式版の対象は **ブラウザで動作する読み取り専用Webツール8種類**です。ResoArc全16機能の正式版宣言ではありません。

1. 一括更新の変更前プレビュー（差分表示のみ）
2. アプリ設定JSON差分比較
3. 権限定義の可視化（実効権限の判定ではない）
4. CSV取込前診断（取り込み可否の保証ではない）
5. 重複レコード候補の検出
6. ルックアップ不整合のファイル照合
7. 統合済みファイルのグループ集計
8. ブラウザ帳票・印刷機能によるPDF保存

**kintoneプラグイン8機能は正式版の対象外です。** インストール形式の署名付きQAパッケージまで準備済みですが、実テナントの権限・保存・競合・モバイル・同時更新試験が残っています。専用のテストアプリへの導入のみを推奨し、本番利用承認は保留します。

## v1.0.0の品質保証範囲

- 入力CSV・TSV・JSONをユーザーのブラウザ内で処理し、ツール自身は外部サーバーへのアップロードやkintone REST APIへの書き込みを行わない。
- 解析エラー時にデータ更新を試みない。形式・上限・異常値を検出する。
- 6つの共通Webツールは共通の単体・Playwrightブラウザテストを実施する。
- 設定差分とCSV取込前診断は追加でPC幅・スマートフォン幅のファイル読込・不正入力・情報マスキング・外部通信検査を実施する。
- 一部の処理は外部のkintoneアプリとの実際の接続や権限確認を含まない。ファイルの内容が最新・完全であるかは利用者が確認する。
- ブラウザ本体、拡張機能、端末、OSの通信や保存操作全般までは検証していない。

## 主な上限と未対応

| 機能 | 上限または既知の未対応 |
|---|---|
| 共通ファイル解析 | 原則1ファイル12 MiB以下、50,000データ行、250列以内 |
| 設定JSON差分 | 1ファイル5 MiB、表示先頭300差分、最大差分5,000件の安全制限 |
| CSV取込前診断 | 1ファイル8 MiB、20,000行、250列、テーブル行構造・ルックアップ等の完全検証なし |
| 重複診断 | 20比較フィールド以内、候補の削除・マージは未実装 |
| 権限の可視化 | ルール定義の一覧化のみで、所属・継承・条件式の実効権限評価なし |
| 横断集計 | 事前統合済みCSV/JSONのみ。kintone自動横断取得や統合は未実装 |
| 帳票・PDF | 5,000行・50列以内。PDF出力はブラウザ標準の印刷ダイアログを使用 |
| 一括更新プレビュー | 差分の事前確認専用、書込みAPIやロールバックなし |
