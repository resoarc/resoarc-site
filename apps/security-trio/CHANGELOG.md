# 変更履歴

## v0.3.0-rc1 (2026-11-08) 実機受入前候補

- **Secret Scout:** 不正なZIP内パスに対して未検査件数を明示。
- **Log Lantern:** 二重エンコードされたパス移動探索を分類に反映。
- **File Inspector:** ZIP内のEXE/スクリプト拡張子を検出、暗号化項目・展開膨張・項目数上限を検査不完全として処理。内容は実行・展開しません。
- **レポート安全性:** 選択フォルダ内の既存ファイルと入力ファイルのハードリンクへの誤上書きを拒否。
- **品質:** 合成データを使った12件の回帰テストを追加し104件合格。Linux/Windows GUI 3モード再試験。Windows 11実機で104件（失敗0、スキップ1）を実行し、3本の未署名EXE生成・起動に成功。

**一般公開 HOLD:** EXEを使った全操作・Explorerドロップ等の追加検証、コード署名、独立レビュー、検出精度評価が残ります。


## v0.2.0 (2026-11-08) 開発プレビュー

- **Secret Scout**: 例示語がトークン中に含まれるだけで既知形式を見逃す問題を修正。存在しない指定ファイル・リンク除外を明示。
- **Log Lantern**: URLのパス部に含まれる長い識別子・メールアドレスをマスク。同一IPプレフィクスの別接続元を混同して集計する問題を修正。
- **Log Lantern**: IIS W3Cの `cs-uri-query` を検出時だけ参照し、出力時に削除。非対応行が混ざる解析の終了状態を「一部未検査」に変更。
- **File Inspector**: 拡張子と認識したPDF・PNG・JPEG・Office形式の不一致判定を追加。ファイルの無害性を保証しない静的検査として表示。
- **共通**: JSON/CSVの両方で未検査・途中終了・解析エラーを記録。レポートの保存先がスキャン対象ファイルと同じ場合は拒否。
- **配布・検査**: GUI 3モードのスモーク試験を継続。Windows CIでGUIテストを追加し、ビルド後に実行ファイル3本のSHA-256目録を作る構成へ変更。
- **品質**: 自動回帰テストを68件から92件へ拡充。Linux XvfbでGUI 3モードを操作確認。100,000行ログの負荷テストを実施。

**公開判定: HOLD。** 署名済みWindows実行ファイルの生成とWindowsでの完全な検収・第三者レビューは未完了です。
