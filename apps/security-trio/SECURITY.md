# セキュリティ設計と報告

## 基本的な脅威モデル

対象は、開発者・小規模サイト運営者・Windows利用者が手元で行う**一次点検**です。入力は攻撃者が作成した可能性のある不正なファイル/ログと想定します。プログラムはコード実行、アーカイブのディスク展開、外部通信を行いません。対応するログと文書の静的な特徴のみを調べます。

## 想定外

マルウェアの完全検知、PDF内部動作のエミュレーション、侵入の証明、資格情報の完全な洗い出し、リアルタイム保護、サンドボックスの提供は対象外です。

## 保護策

- ZIPは項目数、合計容量、1項目の容量、圧縮比を制限し、ファイルとして展開しません。
- シンボリックリンクを走査対象から除外します。
- シークレットのマッチ値は診断記録に含めません。
- 送信元IPは匿名化し、URLのクエリを出力しません。
- CSVには数式インジェクション対策を施します。
- レポートは一時ファイル経由で同一ディレクトリ内へ原子的に置き換えます。検査対象への上書き防止はGUI/CLI側で入力ファイルおよび入力フォルダ内の既存ファイルを確認します。ただし実行中の外部によるファイル差し替えに対する完全な耐性は保証しません。

## 報告

公開リポジトリを用意する場合はGitHubのプライベートな脆弱性報告機能を有効化してください。**脆弱性に実在する秘密や個人情報を公開Issueへ貼り付けないでください。**

第三者レビューとWindows実機試験が終わるまで一般公開する前提で運用しないでください。
