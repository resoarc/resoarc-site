# ResoArc Security Trio 0.3.0-rc1

**3つの無料・オフライン・読み取り専用の日本語セキュリティ点検アプリ**です。Windowsユーザーが、難しいコマンドを覚えずに「公開前の秘密情報」「Webサーバーのアクセスログ」「怪しいファイルの静的な特徴」を確認できるよう設計しました。

> **開発プレビュー版**です。Windows向け署名済み実行ファイルや一般公開版としての品質保証はまだありません。自動判定は警告の手掛かりであり、安全・危険の断定ではありません。

## 3つのアプリ

| ツール | 主な用途 | 主な対象 |
|---|---|---|
| **Secret Scout** | 公開前の秘密情報の混入検出 | `.env`、設定ファイル、ソースコード、ZIP/JARの内部テキスト |
| **Log Lantern** | 不審なログの兆候を日本語で把握 | Apache / Nginx combined access.log、IIS W3C |
| **File Inspector** | 添付ファイルを開く前の静的点検 | PDF、LNK、Office ZIP、Windows PE、スクリプト、ZIP |

### 共通機能

- **オフライン動作**: 内部でHTTP通信・テレメトリー・クラウド送信を行う処理はありません。
- **読み取り専用**: 検査対象のファイルは変更せず、実行しません。ZIPは展開せず読み取ります。
- **統一された日本語UI**: 3アプリを上部タブで行き来できます。
- **ファイル複数選択・フォルダ一括処理**: 限度に達した入力は除外件数として報告。
- **危険度・根拠・確認すること**を分けて表示。
- **JSON / CSVレポート（途中終了・未検査・エラーの情報も出力）**。CSVの表計算ソフトでの数式実行を防止する対策を含みます。
- **サンプルで試す**: アプリ内で無害な模擬データを生成。実在する認証情報は含みません。
- **停止ボタン・バックグラウンド検査**でウィンドウを操作できる状態を維持。
- **ドラッグ＆ドロップ**は任意の `tkinterdnd2` 導入時に利用可能。導入しなくても通常のファイル選択は使えます。

## Windowsで試す（Pythonがある場合）

1. ZIPを**展開**します。ZIP内から直接実行しないでください。
2. **Python 3.10以上**が必要です。標準のtkinterが含まれている必要があります。
3. `SecretScout.pyw` / `LogLantern.pyw` / `FileInspector.pyw` のいずれかを開きます。ファイル関連付けがない場合は同名の `.cmd` を実行してください。
4. 左側でファイルまたはフォルダを追加して **「検査を開始」** を押します。
5. 検出内容の行を選ぶと説明・確認事項が出ます。「傾向と補足」タブで集計を確認できます。「JSON保存」「CSV保存」でレポートを保存できます。

**試すだけなら「サンプルで試す」** を押してください。疑似データを読み込むので、実ファイルを用意する必要はありません。

> 注: Windows Defender / SmartScreenや所属組織のポリシーに反して、実行ブロックを無効化することは推奨しません。

## Pythonなしで動くWindows EXEを作る

このソース配布ZIPに**Windows用EXEそのものは含めていません**。ただし内部評価用の未署名EXE 3本は、2026-11-08にWindows 11のメインPCで生成・起動を確認しました。Windowsマシン上で下記を実行すれば、3本の独立した `.exe` を生成できます。

```bat
py -3 -m venv .buildvenv
.buildvenv\Scripts\python.exe -m pip install -r requirements-optional.txt
build_windows.bat
```

`dist/ResoArcSecretScout.exe`、`dist/ResoArcLogLantern.exe`、`dist/ResoArcFileInspector.exe` が生成対象です。

`.github/workflows/windows-build.yml` はWindows CIでテスト・ビルドし、署名前のEXEをArtifactsに保存する設定です。ワークフローをリポジトリに置いただけでは実行・公開されません。

## CLIモード / 自動化

```bat
py -3 app.py --mode secret "C:\projects\my-app" --output secret-report.json
py -3 app.py --mode log "C:\logs\access.log" --output log-report.json
py -3 app.py --mode file "C:\Users\me\Downloads" --output file-report.csv --format csv
```

CLIの終了コード: `0` = 中・高の検出なし、`1` = 中・高の検出あり、`2` = 一部未検査・上限超過・読み取りエラー・ログの解析不能行・中断・対象なし。`0` は **安全の保証ではありません**。JSON未指定の場合、結果を標準出力へ表示します。レポートも機密情報の可能性があるため管理してください。

## 解析内容と判定の限界

### Secret Scout

- 既知形式の認証情報、秘密鍵の開始行、資格情報付きの接続URI、秘密項目への代入を検出します。
- **マッチした文字列の値を表示・保存しません**。検出種別、行番号、ファイル名のみ表示します。
- ソースファイルは1個あたり最大16MiB。ZIPは1メンバー8MiB、メンバー計64MiB、2000項目まで。走査上限を超えた場合は部分終了を明示します。
- ネストしたZIP、暗号化ファイル、未知の認証情報形式、バイナリや複数行に分かれた秘密情報は一部または全部検出できません。
- 例示やプレースホルダーらしい文字列は誤検知低減のため除外しますが、これは見逃しも生みます。

### Log Lantern

- Apache / Nginx の一般的なcombined形式、IIS W3Cの `#Fields:` ヘッダーを持つログに対応。
- 秘密ファイル探索、ディレクトリ移動、SQL注入らしいアクセス、管理画面探索、80件/分以上の集中、401/403の12件/分以上、404の異なるURL12種類/分以上を**兆候として**通知します。
- 送信元IPは匿名化し接続元IDを振ります。URLのクエリ文字列を削除し、長いIDやメールアドレスらしいパス要素をマスクします。ただし短い識別子などの個人情報が残る可能性があるため、レポート共有前の確認が必要です。
- 1ファイル128MiB・100万行まで（最大50ファイル）。タイムスタンプが読み取れない行は時間別集計に含まれません。
- 403や404、アクセス集中だけでは攻撃の成功も不正アクセスも断定できません。

### File Inspector

- 拡張子とファイル内部の種類の矛盾、二重拡張子、LNK構造、LNK内のコマンド起動文字列、PDFの能動的構造、Office ZIPのVBA・外部参照、ZIPのパストラバーサルと容量膨張、WindowsのZone.Identifier、SHA-256を調べます。
- PDFは先頭2MiBの静的な文字列を確認します。圧縮ストリーム、暗号化PDF、未知のLNK構造など、検出範囲外の動作は見抜けません。
- 最大500ファイル、1ファイル2GiB。**マルウェアスキャナーではありません。** ハッシュが一致しても安全性を保証しません。
- ハッシュ・種類・ファイル名がレポートに含まれます。機密ファイルの名称を不用意に共有しないでください。

## プライバシー

本プログラムはインターネットにアクセスする処理を持ちません。検査対象データはメモリ上で分析し、指定した出力先にのみレポートを書き込みます。サンプルデータは一時ディレクトリに生成し、終了時に削除します（OS上でロック中のファイルは残る可能性があります）。クラウドで実ファイルを解析する機能はありません。
