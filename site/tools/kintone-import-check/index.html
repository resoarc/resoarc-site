取込前チェック

取り込むCSV/TSVと、対象アプリのフォーム定義JSONを選択してください。どちらも利用者のブラウザーで処理します。

UTF-8、8 MiB以下。先頭20,000行まで検査します。

「GET /k/v1/app/form/fields.json」の応答を保存したJSONを使用します。

CSVとフォーム定義JSONの両方を選択してください。

診断結果

判定行列問題・確認事項

一覧表示は最大500件です。検出件数は上部の合計をご確認ください。

表示名とフィールドコードは可能な範囲で照合します。設定によって実際の取り込み結果は変わるため、本結果はインポート成功を保証しません。

02USAGE使い方

フォーム定義JSONの取得

kintoneのアプリ管理権限を持つ利用者が、公式REST API GET /k/v1/app/form/fields.json?app=アプリID で取得したJSONを、ファイルに保存して利用します。ブラウザーの認証情報やAPIトークンをこのサイトへ入力する必要はありません。

診断の判定

「要修正」は解析できない日付・数値、列数不一致、CSVの必須項目空欄などの候補です。「要確認」はマッピング不明、必須列の不足、検査対象外の形式などを意味します。必須項目に初期値がある場合など、実際には問題とならないものも含みます。

プライバシー

選択したファイルは端末のブラウザーで読み込みます。ファイルの内容をResoArcのサーバーに送信する処理はありません。ブラウザーの拡張機能など別の要因については保証できません。
