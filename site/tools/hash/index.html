01FILE INTEGRITY無償ツール

ファイルSHA-256確認

ファイルの内容からSHA-256を計算し、配布元が示すハッシュ値との一致を確認します。

ResoArc.
FILE SHA-256 / VERSION 1.0.0

検証するファイル

ファイルはこの端末のブラウザーで処理します。アップロードは行いません。

仕様と注意事項

計算方式
SHA-256（Web Crypto API）
ファイルサイズ
100 MiB以下
通信
計算時のネットワーク送信なし
動作環境
HTTPSとWeb Crypto API対応の現行ブラウザー
制限
ファイル全体をメモリに読み込むため、大きいファイルではメモリを消費します。

SHA-256が一致してもマルウェアの不存在や配布元の正当性が証明されるわけではありません。信頼できる配布元のハッシュと比較してください。
