ROBOT / BLOCK CODING

ブロックで動かす、ロボットの冒険。

命令を並べて問題を解く。マップも自分で作る。立体的なロボットを動かして、試しながら考えよう。

クォータービューの6×6マップをドラッグして回転。ブロックは並べ替えでき、自作問題はこのブラウザーに保存できます。

クォータービューの問題ボード

マップを左右にドラッグするとカメラが回ります。障害物は手前に来るとロボットを隠します。問題作成モードではマスをタップして配置できます。

配置するものを選んでマスを押そう。

ブロックを組み立てよう

ボタンで追加。ブロックをドラッグして並べ替え。

繰り返しブロックは回数と繰り返す命令を選べます。最大300命令。

学びのポイント

「前進」は上に進むことではありません。ロボットが向いている方向に進みます。失敗したらブロックを変えて何度でも挑戦しよう。

保存した自作問題はこのブラウザー内に保存されます。共有する場合は、個人情報や秘密を問題データに含めないでください。物理ロボットや電子機器とは接続しません。
