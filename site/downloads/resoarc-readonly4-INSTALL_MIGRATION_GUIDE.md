# ResoArc 表示系プラグイン4製品 導入・移行ガイド

対象：フィールド説明表示、QRコード生成、レコード目次、関連アプリリンク（各v0.1.3）

1. 利用中のkintoneアプリ設定・データを控え、検証用アプリで動作を試します。
2. 署名ZIPを解凍せず、システム管理からプラグインを登録します。
3. 各アプリのプラグイン設定から追加し、必要なフィールド等を指定します。
4. 設定を保存した後、アプリの設定を更新してPC/スマホ幅で検証します。

## 各製品の設定

- フィールド説明表示：helpにfieldとtextの組を指定。例：Titleへの入力例。説明文に機密情報を含めないでください。
- QRコード生成：fieldに変換対象フィールド、sizeに画像寸法（例：192）を設定。QR画像は誰でも撮影し得るため機密値を含めないでください。署名ZIP内には第三者OSSのライセンスが含まれます。
- レコード目次：fieldsをカンマ区切りで設定（例：Title,Details）。存在しないフィールドは移動対象外です。
- 関連アプリリンク：labelはボタン名、urlはHTTPS URLのテンプレート（例：https://example.com/?q={{Title}}）。値をURLに埋め込むとリンク先へ送られるので、秘密情報の漏えい防止を確認してください。javascript:等の危険なリンクは禁止。

## 旧版からの移行

旧α・β版との署名ID一致は保証しません。旧設定を控えて旧版を停止、新シリーズを別プラグインとして設定、表示確認後に旧版を解除してください。新旧を同時に有効化しないでください。

## 試験範囲

隔離した実kintone QAアプリ58のPC・ブラウザー模擬iPhone375px/Android412pxで36/36合格。Chromium・Firefox・WebKitの正常・異常系126/126合格。物理スマートフォン固有のSafari/Android OS動作、別ユーザー権限ロール、ゲストスペース全環境での挙動を保証しません。4製品は表示支援が目的で、レコード自動保存は行いません。
