# 郵便番号住所入力 v1.0.1 リリースノート

公開日：2026-11-09

## 変更
- zipcloud等の外部住所検索API利用を廃止。日本郵便の公開郵便番号データを同梱。
- 郵便番号から候補住所を検索し、利用者が明示選択してから入力欄へ反映。
- 郵便番号が複数住所に対応する場合、候補選択が必須。
- 町域未確定のデータは誤った自動反映を防止。
- PCとモバイルの設定互換性、旧版への更新・切戻しをkintone検証アプリで確認。
- iPhone 13 WebKitとPixel 7 Chromiumのエミュレーションで12操作ケース合格、外部検索通信0件。

## 注意
- 日本郵便の2026年10月30日更新データを同梱しています。データは自動更新されません。複数候補や住所未確定の場合は利用者が内容を確認してください。
- 実端末固有の環境・ゲストスペースや他プラグインとの全組合せは未検証です。
