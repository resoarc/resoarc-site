# 郵便番号住所入力 v1.0.1 導入・更新・切戻しガイド

1. kintoneアプリとプラグイン設定をバックアップします。最初にテストアプリで確認してください。
2. システム管理画面から署名済みプラグインZIPを**解凍せずに**登録。v1.0.0から更新する場合は同じIDを利用します。
3. 郵便番号と住所の編集可能な文字列フィールドを設定し、アプリを更新します。
4. レコード作成・編集画面で7桁郵便番号を入力し、候補を確認してから住所を反映します。
5. 複数候補、町域未確定、ユーザー権限、PC・スマホ画面で問題がないことを確認します。
6. 問題がある場合は、バックアップした旧版の署名ZIPを再登録し、設定と関連付けを照合します。

日本郵便の2026年10月30日更新データを同梱しています。データは自動更新されません。複数候補や住所未確定の場合は利用者が内容を確認してください。
