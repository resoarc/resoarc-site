## 既存v1.0.0からの更新
1. kintoneのアプリ設定・レコードを事前にバックアップします。同じプラグインIDを使う全アプリに影響するため、開発・検証環境で先に試してください。
2. kintoneシステム管理 > プラグイン から新しい署名ZIPを解凍せずに読み込んでください。
3. 既存のプラグイン設定が保持されるか、関連アプリで再利用を行う際、指定フィールドのみが初期化されるか確認します。
4. 通常の新規作成と、再利用後の手入力値の維持・保存も試験してください。
5. 別署名IDの旧α/β版は自動更新できません。二重有効化を避けてください。

## 復旧・制限
障害時は影響するアプリを洗い出し、設定・レコードをバックアップ後、旧v1.0.0の署名ZIPへ戻す手順を検証環境で確認してください。自動復旧・完全ロールバックを保証しません。
実スマートフォン、全ロール権限、すべての競合プラグインとの組合せは未網羅です。重要データでの直接試験を避けてください。
