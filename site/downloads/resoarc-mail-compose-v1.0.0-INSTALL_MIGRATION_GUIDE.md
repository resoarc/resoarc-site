# ResoArc メール作成ボタン v1.0.0 導入・更新・撤去ガイド

## 機能
レコードからメール作成画面への導線を表示するプラグイン。外部のメールアプリ起動時の宛先を必ず確認してください。

## 新規導入
1. 対象kintoneアプリの設定・レコードをバックアップし、隔離したテスト用アプリで先に動作確認します。
2. システム管理のプラグイン一覧から、署名ZIPを解凍せずに読み込みます。
3. 対象アプリの設定で本プラグインを追加し、必要なフィールド・表示条件を設定します。
4. アプリの設定を保存・更新してから、PCとスマホ表示で設定内容と動作を検証します。

## 旧0.xからの更新
- v0.1.4からv1.0.0への上書きは、**同一公開鍵・同じプラグインID**でQAアプリ58にて確認済みです。設定保持と他アプリへの関連付けが変わらないことを確認しました。
- 以前の別IDのα/β版は同一IDによる上書き更新を保証しません。両版の重複有効化を避け、検証アプリで設定を移し替えてください。
- 誤送信防止のため、宛先・件名・本文を実際の送信前に必ず確認してください。送信動作は利用者による操作が必要です。

## 障害時・削除
- アプリ内でプラグインを無効化し、設定を更新してください。別署名IDによる旧版への自動戻しは保証しません。
- 操作や表示が不安定な場合、削除前に設定値とレコードのバックアップを確保してください。

## 範囲・注意
QA58での更新と設定保持を検証。すべてのkintoneプラン・カスタマイズ競合・物理端末・権限ロールについて網羅的な動作保証は行いません。
