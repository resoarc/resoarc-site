# ResoArc タブ表示 v1.0.0 導入・アップグレード・撤去ガイド

## 新規導入
1. kintoneの対象アプリ設定・レコード・プラグインの設定内容をバックアップし、先に隔離した検証アプリで試してください。
2. システム管理 → プラグインから署名付きZIPを**解凍せず**読み込み、対象アプリに追加します。
3. プラグイン設定でスペースフィールドのコードと、タブごとのフィールドコードを指定・保存し、**アプリを更新**します。
4. 作成/編集/詳細のPC画面・スマートフォン表示で、切替、すべて表示、キーボード操作、およびほかの表示制御プラグインとの競合を検証します。

## 同一署名IDのv0.1.1から更新
- v0.1.1 → v1.0.0 は**同一署名公開鍵・同じプラグインID**。QA59で同じIDの上書き更新、バージョン確認、アプリ関連付け、設定保持が実証済みです。
- 対象アプリのバックアップ・設定控えを残してから、kintoneシステム管理でv1.0.0 ZIPを同じIDとして読み込みます。更新後、対象アプリが紐付いたままかと設定保持、画面動作を確認してください。
- 過去の別署名IDによるα/β版からの自動上書き更新は**保証しません**。旧版を無効化し、新版を別途導入・設定・検証した後に旧版を削除します。両プラグインを同時有効化しないでください。

## 戻す・削除
- 不具合時はまず対象アプリで新版を無効化し、アプリ設定を更新します。必要なら控えの設定を復元します。
- 古いZIPへの戻しはkintone側が拒否する場合があるため、ダウングレードできることは保証しません。正式版を削除・無効化して別プラグインへ再導入する場合は、検証用アプリで先に確かめてください。
- アプリから解除し、設定更新後にシステム管理から不要なプラグインを削除します。

## 保証範囲
既存の受入はPCとブラウザースマートフォン画面、実kintone QA59、および3ブラウザーです。物理iOS/Android機器のOS固有挙動、ゲストスペース、全ユーザーロールの組み合わせを保証するものではありません。すべての機能はMITライセンスに基づいて無償提供します。
