SWWW 脆弱性天気予報 / 公開API

SWWW 公開API・データ配信

一般公開の脆弱性情報を第三者が再利用できるよう、JSON検索APIとXMLフィードを提供しています。認証不要・読み取り専用です。

対象は公開承認済みの日次スナップショットです。過去の全CVEを網羅するDBではなく、配信日の情報・集計範囲・取得品質を必ず確認してください。

JSON API

  • Javaの脆弱性情報を検索（JSON）
  • Oracleの脆弱性情報を検索（JSON）
  • 重大度CRITICALだけを検索
  • 日次サマリー
  • 技術タグと件数
  • OpenAPI 3.1 仕様

絞り込みは q、technology、severity、source、date、exploited、page、limit を指定できます。1ページの取得上限は100件です。

XML・購読用フィード

  • XML（公開カタログ全件）
  • RSS 2.0（最新100件）
  • Atom 1.0（最新100件）
  • JSON Feed 1.1（最新100件）
  • 公開カタログ（JSON一括）

安全性と利用条件

配信データにResoArc内部のホスト、担当者、調査メモ、非公開の対策手順は含めません。技術タグはアドバイザリー本文に登場した技術を示すもので、ResoArcでの使用・影響を証明しません。

原文の著作権・ライセンスは各提供元に帰属します。詳細な修正情報はリンク元で確認してください。ResoArcの統合集計に第三者の権利まで含む再配布許諾が与えられているわけではありません。

毎日の公開更新は現状手動審査制です。RSS等の更新日時が古い場合、現在の安全状態を示しません。CORS対応のJSON APIは非認証・読み取り専用で提供しています。
