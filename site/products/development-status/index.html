01 / LOCAL-FIRST BACKUP

バックアップ・移行

開発・配布物の内部検証完了　／　一般提供は未開始

kintoneの取得可能なレコードや添付ファイルを利用者自身のPCへ保存し、ローカルビューアで確認。別のアプリへの追記復元を支援する仕組みです。署名済みkintoneプラグインZIPではなく、カスタマイズJavaScriptとオフラインビューアの組み合わせです。

確認したこと

自動試験116件、隔離した実ブラウザーで合成501件の復元フロー、配布候補ZIPの展開・オフライン閲覧検証22項目を合格。別の隔離環境でも合成3,001件の中断・手動再開・再実行時の重複防止を検証しました。

正式提供までに

配布形式・利用条件・導入/復元手順・既知の制限を整理し、公開版の最終判断を行います。現段階では一般向けダウンロードリンクは掲載しません。

注意点：未暗号化のバックアップは機密情報を含む平文です。暗号化時も索引の一部メタ情報が平文で残る場合があります。すべてのkintone設定・権限・監査履歴を完全再現する機能ではありません。

02 / TEST & EVIDENCE

Test Ledger

開発テスト完了　／　Excelデスクトップ実機の最終受入待ち

テスト観点のマトリクスからテストケースを作成し、結果・実施者・実施日・証跡画像をまとめるWebツールです。Excelおよび証跡一式ZIPを書き出せます。

確認したこと

実ブラウザーから出力したExcelと証跡ZIPを15項目検証。4シート構成、添付画像、相対リンク、数式として扱わせない文字列出力を確認しました。容量不足を模擬した場合の保存ロールバックも確認済みです。

正式提供までに

Microsoft Excelデスクトップ版で実際に開き、証跡リンクが動作するかの確認が未完了です。この実機検証を通過するまで正式提供しません。

データの扱い：台帳や証跡はブラウザーのローカル領域に保存する方式です。サーバーへの証跡アップロード機能はありませんが、ブラウザーのサイトデータ削除で失われる可能性があり、出力ZIPは既定では暗号化されません。

03 / ACCESSIBILITY

Live Japanese Captions

拡張機能の開発テスト完了　／　ストア掲載審査前

PCブラウザーで再生する動画への日本語字幕表示を支援する拡張機能を開発中です。端末内で処理するローカルモードと、利用者が選択する外部音声認識モードを検討しています。

確認したこと

20項目の機能テスト合格、実際のブラウザー拡張機能としての設定画面起動・撮影。第三者ライブラリのライセンス表示を見直し、配布候補へ通知文書を収録しています。

正式提供までに

実際の動画での連続字幕表示と操作検証、残る第三者素材の権利確認、プライバシー情報の公開、ストア申請審査が必要です。

通信・費用：ローカルモードでも初回のモデル取得には通信が必要です。外部サービスを選択した場合は音声の外部送信と従量課金が発生することがあります。事前同意と費用説明を確認するまで配布しません。

04 / SCHEDULED WORKFLOW

Clock / Batch Flow

安全停止・模擬障害試験済み　／　実定期実行の受入待ち

設定した時刻・条件でワークフローを動かし、障害発生時の確認・手動復旧を支援する機能を開発中です。

確認したこと

権限外操作を拒否する安全ガード9項目と、処理完了後に通信応答が失われるケースを模擬した停止・確認・復旧のフローを検証しました。

正式提供までに

隔離した実環境でのスケジュール起動、障害後の二重実行防止、手動復旧、実行停止・試験データ撤収までを検証します。現在は自動実行を有効化していません。

注意：模擬試験の合格は、実際の定期実行の成功を示すものではありません。実データへの自動書込みは正式検証完了まで提供しません。

公開の判断は、試験結果と分けて行います。

技術試験の合格、ライセンスと利用者向け説明の確認、正式な配布開始の判断はそれぞれ独立した工程です。進捗は更新される可能性があります。正式提供が決定した製品のみダウンロードページで案内します。
