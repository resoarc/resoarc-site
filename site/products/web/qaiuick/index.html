PUBLIC BETA · v0.2AI-NATIVE MICRO WEB FRAMEWORK

小さく書いて、
すぐ動かす。

AIにも、人間にも、わかりやすく。複雑な開発環境を用意せず、読みやすいHTMLと少しのJavaScriptで、美しいWebアプリを作るための無料ツールキット。

ブラウザで試す ↗ベータ版をダウンロード ↓

登録不要 / MIT License / ビルド不要 / 対応：モダンブラウザ

01 / THE IDEA

複雑さを減らす。
可能性は、そのまま。

AIが生成したコードでも、読みながら手で直せる。ひとつの小さな設計ルールが、試作から改良までをつなぎます。

01

読むだけで、わかる。

q-model、q-actionなど少数のHTML属性だけで状態と操作を表現。AIが書いたものを、人間が追えます。

02

最初から、きれい。

フォーム・カード・リスト・テーブルの見た目を標準化。3つのテーマとモバイル表示に対応します。

03

データを、閉じ込めない。

ブラウザ保存とメモリ保存、HTTP APIを共通の操作で扱えます。SQLiteはローカル実行用サンプルを同梱。

02 / CLEAR BY DESIGN

コードが、
そのまま設計図になる。

HTMLは「何を表示するか」、JavaScriptは「何をするか」に分ける。ビルドツールや独自テンプレート式は不要です。

動くサンプルを開く ↗
index.htmlreadable by AI + humans
<section class="q-panel">
  <h2>今日のメモ <span q-text="count"></span></h2>

  <form q-submit="add" class="q-form">
    <input q-model="draft" placeholder="メモを入力">
    <button>追加する</button>
  </form>

  <template q-each="tasks" q-as="item">
    <p q-text="item.title"></p>
  </template>
</section>

03 / START SMALL

まずは、3つのステップ。

01

ZIPを展開

インストーラー不要。配布物のsrc/とexamples/が出発点です。

02

HTMLを開く

ローカルサーバーからサンプルを表示。見た目や動きをそのまま変更できます。

03

AIと改良

AGENTS.mdとdocs/AI_SPEC.mdで、設計と編集ルールを共有します。

04 / BETA NOTES

まだ、小さな実験室です。

v0.2は試験公開版です。SQLiteのサンプルサーバーはlocalhost専用・認証なしで、インターネットには公開できません。ブラウザ内SQLite（WASM/OPFS）、マルチユーザー認証、DB同期、PostgreSQL/MySQL連携は未実装です。

ブラウザの保存データはバックアップではありません。重要なデータを預けず、まずはサンプルで挙動を確認してください。安全性や商用運用への適合を保証するものではありません。
