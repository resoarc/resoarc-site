PUBLIC BETA · v0.4AI-NATIVE MICRO WEB FRAMEWORK

小さく書いて、
すぐ動かす。

AIにも、人間にも、わかりやすく。複雑な開発環境を用意せず、読みやすいHTMLと少しのJavaScriptで、美しいWebアプリを作るための無料ツールキット。

7つのサンプルを試す ↗ベータ版をダウンロード ↓

登録不要 / MIT License / ビルド不要 / 対応：モダンブラウザ

01 / THE IDEA

複雑さを減らす。
可能性は、そのまま。

AIが生成したコードでも、読みながら手で直せる。ひとつの小さな設計ルールが、試作から改良までをつなぎます。

01

読むだけで、わかる。

q-model、q-actionなど少数のHTML属性だけで状態と操作を表現。AIが書いたものを、人間が追えます。

02

最初から、きれい。

フォーム・カード・リスト・テーブルの見た目を標準化。3つのテーマとモバイル表示に対応します。

03

データを、閉じ込めない。

ブラウザ保存とメモリ保存、HTTP APIを共通の操作で扱えます。SQLiteはローカル実行用サンプルを同梱。

02 / CLEAR BY DESIGN

コードが、
そのまま設計図になる。

HTMLは画面だけ。JavaScriptはデータと必要な操作だけ。追加・削除・保存・画面更新などの定型処理を省き、少ないコードで完成させます。

動くサンプルを開く ↗
main.jsreadable by AI + humans
import { quickApp } from './quick.js';

quickApp({
  key: 'my-todo',
  data: { draft: '' }
});

03 / SPEC-FIRST DESIGN

仕様を書くだけで、
画面が完成する。

項目・一覧・検索・操作をひとつの宣言にまとめます。追加・編集・削除・入力検証・保存・見た目はフレームワークが担当。生成された画面から実装仕様JSONと変更差分を確認できます。

仕様駆動の在庫管理を試す ↗
inventory.spec.jsspec as code
import { defineApp } from './define.js';

defineApp({
  id: 'stock-demo',
  version: 1,
  title: '在庫管理',
  fields: {
    name: '品目名*',
    qty: { label: '数量', type: 'number', min: 0 }
  },
  ui: { search: ['name'] }
});

06 / BETA NOTES

まだ、小さな実験室です。

v0.4は試験公開版です。SQLiteのサンプルサーバーはlocalhost専用・認証なしで、インターネットには公開できません。ブラウザ内SQLite（WASM/OPFS）、マルチユーザー認証、DB同期、PostgreSQL/MySQL連携は未実装です。

ブラウザの保存データはバックアップではありません。重要なデータを預けず、まずはサンプルで挙動を確認してください。安全性や商用運用への適合を保証するものではありません。
