保存後画面遷移

v0.1.3 / RC9確定配布版 / 2026年10月19日

レコードの新規保存・編集保存が成功したイベントだけで、一覧画面、新規作成画面、現在の画面維持、または同一オリジンのHTTPS URLへの遷移を設定します。

署名済みプラグインZIPをダウンロード ↘

SHA-256
6e281275e2eb276e7886d8dc562852e194b4002ce05625b75a10326b0e527fd8

署名プラグインID
elchlflcbmdgdhifeihibkdpapnaiahc

ZIPは解凍せずkintoneへ登録してください。ライセンスはMITです。ResoArcはサイボウズ公式の開発元・推奨製品ではありません。

導入と確認

  1. 対象アプリの既存設定・データを控え、バックアップを取得します。
  2. システム管理 → プラグイン → 読み込むから署名ZIPを登録します。
  3. アプリの設定 → プラグイン → 追加で選び、設定後にアプリの設定を更新します。
  4. 保存後の遷移先として list（一覧）、create（新規）、stay（維持）または同一オリジンHTTPS URLを指定します。
  5. 設定を保存し、検証用アプリで保存成功時の遷移を確認します。
  6. 権限不足、通信失敗、保存拒否時に意図せず移動しないか確認します。
  7. 業務環境へ反映する前に検証用アプリで十分に確認します。
旧α・β版との互換性に注意

旧版との署名IDの同一性は確認されていません。旧版を上書きせず、新しいIDの製品として導入してください。同時に有効化すると処理が重複する可能性があるため、ガイド記載の切替手順を守ってください。

対応範囲・検証状況

実kintone QAアプリ58でPC保存成功10/10、403注入6/6・429注入6/6、PC/ブラウザースマホモードの保存・遷移を検証。403/429は通信注入による再現で、別権限の実ユーザーによるテストではありません。

物理スマートフォン固有のSafari/Androidブラウザー動作と、ゲストスペースの特殊な構造は保証対象外です。

注意事項：外部サイトや javascript: URLへは遷移しません。通信障害や403/429では成功イベントが発生しない限り移動しません。実ロール別の権限拒否試験やゲストスペースの特殊URLは未保証です。
