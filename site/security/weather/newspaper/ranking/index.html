Next.js画像処理に重大な問題。SVG経由の遠隔コード実行に注意

Next.jsの画像最適化機能で、特定のLinux環境と依存ライブラリの組み合わせにより遠隔コード実行につながる可能性が報告されました。すべてのNext.jsサイトが影響を受けるわけではありません。

CRITICALNext.js / SVG
原文を確認 ↗
確認することNext.js 15系は15.5.28以降、16系は16.4.1以降を確認。関連するsharpのバージョンも確認。

対象：Next.jsを運用する人

02

Next.js「use cache」に別の重大欠陥。特定の戻り値が条件

App RouterのCache Componentsで、複数の型付き配列を返す「use cache」関数がある場合、遠隔コード実行につながり得る問題です。提供元は16.4.1への更新を案内しています。

CRITICALNext.js / Cache
原文を確認 ↗
確認することNext.js 16.0.0〜16.4.0の利用有無を確認し、16.4.1以降への更新を検討。

対象：Next.js 16系の開発者

画像処理ライブラリPillowで、複数フレームの画像を読み込む際にメモリ破壊が起こる問題です。特定の実行環境でコード実行を示す検証も報告されています。

CRITICALPillow / Python
原文を確認 ↗
確認することPillow 11.0.0〜12.3.0の利用と、外部画像を自動処理する機能の有無を確認。修正版13.0.0を確認。

対象：画像アップロードを扱う人

04

ログイン用トークンの信頼が揺らぐ。PyJWTの鍵設定に盲点

JWK方式で空のHMAC鍵を受け入れると、条件次第で偽造トークンの検証が通る可能性があります。一般的なJWTすべてが破られるという意味ではありません。

HIGHPyJWT / 認証
原文を確認 ↗
確認することPyJWT 2.13.0以前かを確認。JWK/JWKSの鍵設定と2.14.0以降への更新を確認。

対象：API認証の担当者

05

HIGHNext.js / DoS
原文を確認 ↗
確認することServer Actionsの利用有無を確認。15系15.5.28、16系16.4.1以降などを参照。

対象：Next.js運用者
