PHPの重大な脆弱性に関するセキュリティ更新対応のお知らせ

2026年10月22日 ｜ ResoArc Open Technology Project

PHP開発元は2026年10月21日、遠隔からの不正なコード実行につながる可能性がある2件の重大な脆弱性（CVE-2026-109618、CVE-2026-109619）を修正したセキュリティ更新版を公開しました。

ResoArcでの対応状況

ResoArcが管理する対象のPHP稼働環境について、修正済みのPHP 8.2.35が適用されていることを確認しました。コマンドライン実行環境とWebサーバーで利用するPHP-FPMの両方で当該バージョンを確認し、関連サービスの稼働およびPHP-FPM設定の検査を実施しています。

上記は該当する更新と稼働状況の確認であり、すべてのソフトウェアに脆弱性が存在しないことや、過去に不正アクセスが一切なかったことを保証するものではありません。

継続する対策

既知の脆弱性情報・新しい修正の監視を継続するとともに、サービス稼働の確認、公開配布ファイルの整合性確認、依存ソフトウェアの更新管理を行います。PHP 8.2は2026年12月31日でセキュリティサポートが終了する予定のため、サポート対象となる後継系への移行準備も進めます。

利用者の方へ

今回の対応に伴うResoArcの公開Webツール・kintoneプラグインの新たな操作や再インストールは、現時点では案内していません。ただし、利用者ご自身が管理するPHP環境では、開発元の情報に従い、該当バージョンを速やかに更新してください。
