# ResoArc Excel風一覧編集 v0.1.0-alpha

ソースコード・単体試験用の開発α版です。公開配布用の署名ZIPではありません。実機試験完了前に本番アプリへ導入しないでください。

一覧の現在ページのみが対象です。更新できるのは通常文字列・複数行文字列・数値フィールドで、日付・計算・その他のフィールドは対象外です。プレビュー、型チェック、明示確認後にGETで全対象レコードの更新直前の値・リビジョンを照合し、変更がなければ最大100件を一度のリビジョン付きPUTで更新します。kintoneの複数件更新APIは1件でも失敗すればそのリクエストを取り消します。通信が切れた場合は結果不明のため再送信せず、再読込して状態を確認してください。
