# ResoArc 高機能検索・絞り込み v0.1.0-alpha

ソースコード・単体試験用の開発α版です。公開配布用の署名ZIPではありません。実機試験完了前に本番アプリへ導入しないでください。

検索は初期状態では表示中の一覧ページだけを対象とします。ユーザーが広域検索を選択して実行したときだけ、現在の一覧条件を維持しつつ最大2,000レコードをkintone内のGET APIで読み取ります。実行時の権限が適用されます。100件を超える結果はUIで省略し、取得上限を超えるレコードは検索できません。更新APIや外部送信は行いません。
