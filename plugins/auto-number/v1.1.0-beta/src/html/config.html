自動採番プラグイン

kintoneのレコードIDから、重複しない識別番号を設定します。連番の穴埋めや年次リセットではなく、同時保存時の重複防止を優先しています。

通常フィールドおよびテーブル内の「文字列（1行）」に対応します。必須入力・ルックアップ・自動計算は対象外です。

半角英数字・ハイフン・アンダースコア（20文字以内）

上限桁数を超えた場合、番号は切り捨てません。

レコードIDが1のときの番号です。通常は1のままにしてください。

運用上の注意
  • 保存に成功した後、REST APIで採番欄を更新します。レコードに編集権限がない場合は更新できません。
  • レコードを削除しても番号は再利用しません。テーブル内の場合は「レコード番号-行ID」とし、行の移動・削除でも既存値は変更しません。
  • 採番前の空欄を許可するため、採番先フィールドを「必須」にしないでください。
  • CSVインポート・REST APIによるレコード新規登録には本プラグインのブラウザーイベントが発生しません。
  • テーブルは保存後に行IDが確定するため、採番に失敗した場合は再試行してください。既存の全行IDを指定して更新し、削除の事故を防ぎます。
  • 採番ルールは運用開始後に変更しないでください。過去の番号は自動変更されません。
