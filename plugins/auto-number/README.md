# ResoArc 自動採番プラグイン v1.0.0

kintoneレコードIDから番号を作成する、無償・MIT Licenseのプラグインです。

## 採番例

設定：接頭辞 `INV-`、幅6桁、開始番号1。レコードIDが1なら `INV-000001`、12なら `INV-000012`。

## 特徴

- PC・モバイルのブラウザーで新規作成したレコードに対応。
- 同時登録でもレコードIDを一意な採番源とするため、採番元の競合なし。
- 既に値がある場合は上書きしない。
- 保存後の更新が失敗した場合、詳細画面に再試行ボタンを表示。
- 依存ライブラリ・外部サービス・APIトークン不要。kintone自身のGET/PUTのみ。

## 事前準備

1. フォームに「文字列（1行）」フィールドを1つ用意。**必須にはしない**。ルックアップも避ける。
2. レコード・採番先フィールドへの編集権限があることを確認する。
3. プラグインの設定画面から対象フィールド、接頭辞、表示桁数、開始番号を指定する。
4. アプリの設定を更新（アプリを公開）してから、新しいレコードを保存して確認する。

## 重要な制約

- **欠番は発生します。** 既存レコードの削除、IDの消費、データ取り込みなどで発生した番号を詰めません。
- **保存後の非同期更新**です。作成された直後から短時間、採番欄が空になる可能性があります。
- REST APIによる作成、CSV読み込み、外部連携などではブラウザーイベントは発生しないため自動付番されません。空欄レコードの詳細画面で手動再試行できます。
- 採番先フィールドを必須にしないでください。採番元がレコードIDなので保存前は番号が確定しません。
- 自動採番を行うユーザーにレコード・フィールド編集権限が必要です。
- 接頭辞などを途中変更すると番号体系が混在します。既存値は変更しません。
- レコードIDはアプリ単位です。複数アプリを横断した番号の一意性は保証しません。
- ゲストスペース、サブテーブル、プロセス管理連携、大量一括採番は初版の検証対象外です。
- プラグインは他のJavaScriptカスタマイズとの組み合わせ次第で影響を受けることがあります。
