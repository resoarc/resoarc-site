条件付き表示・入力チェック

条件が成立した場合に対象フィールドを表示し、必要なら保存時に入力必須として検証します。非表示にしても入力済みの値は削除されません。

注意

対象フィールドにkintoneの「必須」を設定すると、条件不成立時でもkintone標準の入力検証が働く場合があります。条件付き必須にするフィールドはフォーム設定で必須をOFFにしてください。実業務導入前に必ず検証してください。

ルール一覧

最大30ルールです。対象のフィールドを別のルールで繰り返し指定することはできません。設定変更後はアプリの更新が必要です。
