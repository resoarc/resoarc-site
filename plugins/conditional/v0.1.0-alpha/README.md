# ResoArc 条件付き表示・保存時入力チェック 0.1.0-alpha

実際のフィールドデータを消さずに、設定された条件に基づいてフィールドを表示・非表示にします。保存時には、条件に合う場合だけ対象項目に入力エラーを表示できます。

## 仕様

- ドライバーフィールドと対象フィールドを別々に指定。
- 条件：一致・不一致・部分一致・空欄・空欄ではない・数値比較。
- 条件成立時は対象フィールドを表示。条件不成立時は非表示。
- 必須オプションがONの場合、条件成立かつ対象未入力のとき保存を拒否。
- 対象の値を自動的には削除しません。
- UI上の必須チェックはレコードイベントによる検証です。**kintoneのフォーム必須属性やアクセス権を変更するものではありません**。
- 通常フィールド対象。テーブル内フィールドおよび異なるプラグインとの制御競合は試験対象外。
- 最大30ルール、1つの対象フィールドは1ルール。
- PC・モバイル対応を目指していますが、kintone実機試験は未完了です。

**開発中のアルファ版です。実業務への適用はしないでください。**
