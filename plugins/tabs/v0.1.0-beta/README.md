# ResoArc タブ表示プラグイン v0.1.0-beta

kintoneのフィールド表示・非表示を、公式JavaScript APIで切り替える無料プラグインです。

## 準備

1. フォーム先頭にスペースを追加し、要素IDを `resoarc_tabs` に設定する。
2. プラグインZIPをkintoneシステム管理へ読み込む。
3. 対象アプリでプラグインを追加。タブ名と各タブの通常フィールドをチェックボックスで指定。
4. 保存して「アプリを更新」を実行する。

## 仕様

- PC・モバイルの新規・編集・詳細画面向け。
- タブは最大12個、管理対象フィールド最大100件。
- 他のフィールドは非表示にしません。
- 操作中の保存イベントではすべてのフィールドを表示へ戻す設計。標準の必須入力検証が先に発生する場合などがあるため、保存前の「すべて表示」を推奨します。
- テーブル内項目は選択対象外。スペースフィールドが見つからないときは切り替えを実行しません。
