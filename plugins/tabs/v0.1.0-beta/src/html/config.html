RESOARC / KINTONE PLUGIN / BETA 0.1.0

タブ表示プラグイン

kintoneの公式フィールド表示・非表示APIで、通常フィールドをタブ切り替え表示します。画面構造を直接書き換えない方式です。

事前にフォームへスペースを追加

フォームの先頭に「スペース」フィールドを追加し、要素IDを resoarc_tabs にしてください。対象はテーブル内を除く通常フィールドです。必須フィールドを隠す場合、保存前に「すべて表示」で確認してください。

タブと対象フィールド

各タブに1つ以上のフィールドを割り当ててください。フィールドの重複指定はできません。

保存後、必ず「アプリを更新」してください。開発環境で動作確認後に運用利用してください。
