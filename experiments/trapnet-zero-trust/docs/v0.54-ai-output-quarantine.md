## New implementation
- `sonar/ai_response_quarantine.py`: standalone Python stdlib-only **offline** command, inputs `--packet` (previous validated aggregate packet) and `--model-response` (untrusted model reply). It has **no model API or network client**, no subprocesses, no signature code, no file writes and no operational controls. JSON data is bounded (4096/1024 bytes), duplicate keys rejected at any depth, and unsafe file types or symlinks refused (O_NOFOLLOW when supported).
- Input packet must be exact, allowlisted privacy-safe schema from the preexisting advisory pipeline. Model reply must contain exactly `schema`, `advisory_code`, `confidence`; code and confidence must be known enums. No free text, raw IP, credential, action, node ID, URL, arbitrary nested structure or markdown fences. A valid hypothesis is checked against categories/status bands, never taken as a verified attack or causal inference. `review_data_integrity` is explicitly not derivable from aggregates and is rejected.
- Accepted output includes only fixed advisory codes, packet SHA256, `requires_human_review:true`, zero actions, and explicit `sent_to_hub:false`, `sent_to_guardian:false`, `can_sign_feeds:false`, `release_approved:false`, `ai_pipeline_integration_verified:false`.
- Rejected input produces only fixed non-leaking JSON fields with `status:rejected`; exit code 2. The model output is never executed, copied into a feed, signed or published.
- `protocol/ai_advisory_non_authority_test.go` asserts representative AI-review JSON and forged control objects cannot verify as valid Ed25519 signed reports or Guardian feeds.

## Limits and release gate
- The new component is deliberately **not wired to production**. A standalone CLI that refuses operations does not prove that a future integration cannot accidentally grant privileges.
- Runtime tamper resistance, model prompt-injection resilience, a deployed AI host's actual permissions, long-lived log provenance, signed feed key isolation and independent human attestation remain separate verification.
- The module does not attest to system-wide absence of network or process calls. It contains no such calls itself, and local tests mock those interfaces at the tested function boundary.
- **E2 remains PARTIAL; formal general release HOLD. Whole-program gates unchanged: PASS 1 / PARTIAL 17 / TODO 2.** No production VPS/service/firewall, public port, Guardian policy, signed feed, main branch, or customer data changed.
