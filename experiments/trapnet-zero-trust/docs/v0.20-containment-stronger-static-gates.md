# TrapNet v0.20: stronger Sonar static containment gate

**Scope:** Draft PR only. The currently running VPS Sonar containers were not
reconfigured, restarted, stopped or updated. Public Sonar beta remains HOLD.

The static read-only Docker inspector now has **15 controls per service**.
Beyond the existing 13, two additional checks verify:

- `tmpfs_scoped`: only explicitly approved private paths are allowed
  (`/tmp`, and `/cowrie/cowrie-git/var` for SSH); require `nosuid`,
  `nodev`, `noexec`, a valid bounded size and no unexpected writable path.
  Inspect `HostConfig.Tmpfs` as well as existing `Mounts`. Web/edge
  deployments already have properly restricted `/tmp` tmpfs settings.
- `namespaces_and_devices_private`: reject host PID/IPC/user namespace,
  inherited volumes, device passthrough and permissive device cgroup rules.

The earlier throwaway Cowrie test proved a read-only root filesystem and
an internal SSH port could coexist, but **JSON logging was broken**. Cowrie
attempted to open `var/log/cowrie/cowrie.json` on a fresh private tmpfs,
which lacked its required subdirectory. A follow-up command to create this
path inside a new throwaway container was blocked by the runtime safety
review and was not carried out. Therefore full read-only Cowrie startup and
log persistence are **NOT** established.

`cowrie_workspace.py` validates the private writable hierarchy without
creating files or touching deployment. It requires `log/cowrie`, `run`
and `lib/cowrie`, rejecting symlink escapes. Passing that preflight is
necessary but **not sufficient** for approval. The production Cowrie still
has writable root and writable `/cowrie/cowrie-git/etc` configuration volume.

`safe_analysis_input.py` separately limits *optional future* AI advisory
data to fixed coarse categories and no commands, IPs or raw text. This is
only a schema gate and **does not prove** the truth of unverified input
or a deployed model's prompt-injection robustness.

## Verification

28 local Python unit tests succeeded/skip accounted for (Windows: 27 passed,
1 symlink test skipped due to lacking symlink privilege), and syntax compiled.
The GitHub Linux runner must execute the same test suite, including symlinks.
CI success alone never approves public distribution.

## Release HOLD

Before Sonar operator beta: configure and test a fully isolated read-only
Cowrie **with working JSON logging**, review permissible writable mounts,
measure actual firewall/egress isolation, test bounded storage and crash
recovery, audit published/runtime-source parity, and obtain an independent
human security review. No household Stick PC honeypot on the current LAN.
