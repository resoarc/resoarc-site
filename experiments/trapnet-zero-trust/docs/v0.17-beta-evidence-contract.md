# TrapNet v0.17 beta release-gate evidence contract

**Development-only.** This parser never publishes, signs, installs, or approves a real release.

Each evidence report must identify the **exact reviewed source commit** (40 lowercase hexadecimal characters), **exact candidate digest** (64 lowercase hexadecimal characters) and 11 independently reviewable checkpoints. Every checkpoint must include `passed: true`, an HTTPS evidence reference, and repeat both identifiers. Cross-release evidence mismatches, plain booleans, invalid locations and missing pins fail closed.

Example **synthetic shape** (not proof of compliance):

~~~json
{
  "source_commit_sha": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
  "candidate_sha256": "bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb",
  "checks": {
    "source_revision_pinned": {
      "passed": true,
      "evidence": "https://github.com/resoarc/resoarc-site/actions/runs/123456789",
      "source_commit_sha": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
      "candidate_sha256": "bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb"
    }
  }
}
~~~

A record with only this example has **10 outstanding checkpoints**. A forged set of 11 self-reported checks can still match the schema, so `ready_for_human_decision` is **NOT a security attestation, signature, release approval, or automatic GO**. A reviewer must authenticate the evidence source, reproduce relevant tests, verify publisher trust and confirm the approved artifact matches its digest. Production Guardian beta remains HOLD pending actual signing-key custody, independent security review, upgrade/recovery exercise and explicit release authorization. The live Sonar VPS is unaffected.

Earlier schema v1 bare links do not automatically upgrade or carry over to another release candidate.
