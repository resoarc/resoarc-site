# TrapNet v0.7: OFF-HUB recovery inspection (EXPERIMENTAL / HOLD)

This version adds the **read-only** `cmd/recovery-check` forensic triage utility and deterministic HUB crash-window tests. It never repairs, truncates, restarts, clears locks, or authorizes public deployment.

## Preconditions

- Stop HUB, preserve original evidence, and use a stable OFFLINE COPY of both `ledger.jsonl` and `ledger.jsonl.head`.
- Retrieve Witness history, pinned Ed25519 public key and the **latest independently published/pinned tip** from storage not administered by the HUB. A forged locally supplied anchor defeats the model.
- Do NOT remove a stale `.lock` automatically or bootstrap signatures to conceal evidence loss.

```sh
go run ./cmd/recovery-check \
  -ledger /offline/evidence/ledger.jsonl \
  -history /offhub/witness/history.jsonl \
  -pub /offhub/keys/witness-public.hex \
  -expected-tip <externally-pinned-witness-tip>
```

## Decision table

| Result | Meaning | Action |
| --- | --- | --- |
| `fully_witnessed` (exit 0) | Closed evidence matches latest supplied external Witness boundary | Preserve and independently verify that this is genuinely the newest anchor. Manual incident review before any HUB restart. `may_start_hub` stays false. |
| `unwitnessed_tail` (exit 1) | Authenticated prefix matches but complete later rows have no off-HUB signature | Quarantine and review; do NOT truncate, auto-seal, or restart |
| `REJECT` (exit 1/2) | Incomplete, corrupted, unsigned, wrong signer, stale pin, missing checkpoint or lock | Investigate with independent copies; no silent repair |

New tests simulate: a synced row before `.head` update; a checkpoint ahead of data; missing/modified checkpoint; torn/truncated rows; forged anchors; shortened Witness history; lock and symlink. This is **not** a real power-loss, fsync-durability, disk-full or physical five-host drill.

## Security limits and next gates

1. A formerly accepted event may be lost on rollback, re-opening replay windows. Hence this tool **does not restore a service**.
2. Cryptographic continuity proves file bytes, **not truthfulness**, node independence, privacy compliance, or the absence of a compromised off-host witness.
3. Physical disk-full/power-cycle tests, off-host custody, key/root rotation, multi-operator five-host isolation, supply-chain update checks, privacy review and signed release remain incomplete.
4. Keep Draft PR #32 and the prohibition on public Sensor enrollment, remote commands and auto-blocking.
