# TrapNet v0.14: fail-closed offline review and correlation hygiene

Status: development-only; Draft PR, **no production HUB deployment**.

## Changes

The offline `cmd/corroborate` tool now refuses a trust registry or evidence
ledger supplied through a symlink or nonregular file. It binds each original
path to an already-open descriptor, preventing silent pathname substitution.
It rechecks path identity and the externally pinned SHA-256 on **both** inputs
after analyzing them, and re-verifies the signed Witness history and pinned
checkpoint tip before emitting **any** result.

This is defense in depth, not a replacement for an immutable closed snapshot,
offline Witness key custody or physical host isolation. A privileged attacker
who can change the verifier itself is outside this protection.

The `correlate` grouping key now includes the report's `target_port`,
in addition to the claimed campaign fingerprint, kind and UTC time bucket.
Identically fingerprinted SSH and HTTPS reports are distinct review cases.
Two registered nodes from different reviewed groups do not establish attacker
identity or malicious intent: they still trigger **manual review only**.

## Deterministic regression checks

- Reject symlinked trust/ledger evidence.
- Reject a pathname replacement with identical bytes.
- Reject post-validation in-place changes.
- Reject directories masquerading as files.
- Keep same-fingerprint events on different target ports separate.
- Retain earlier tests for signature tampering, stale Witness tip, unobserved
  ledger tail, unreviewed operators, rollback and replay.
- Go full test suite, Go race detector and `go vet` passed locally.
- Synthetic end-to-end fixture: offline Ed25519 attestation, independently
  pinned Witness tip, and correlation CLI returned
  `multi_operator_candidate_for_manual_review` only.
- Negative CLI trial with a wrong tip produced no review result.

The synthetic fixture uses *one* test operator who created all fake node
identities. It does **not** establish real-world multi-operator independence.

## Production boundaries

The deployed Sonar v3.2 Web/SSH decoys and privacy snapshot timer are unchanged.
Do not upload this development corroboration code to production until a separate
change review, an externally anchored real closed-ledger drill, incident/rollback
procedure and privacy review. Home Stick PC remains unsuitable as a public
honeypot without router-enforced VLAN isolation. Guardian must remain read-only.

The public repository intentionally does not include deployed Sonar IPs,
operational credentials, sensitive raw observation logs or node-specific
fingerprinting profiles.
