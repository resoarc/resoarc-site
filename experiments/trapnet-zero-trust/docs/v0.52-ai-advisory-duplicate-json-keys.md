## Change

Python's default JSON decoder silently accepts duplicate object keys with last-value-wins semantics. Reject all duplicate keys, including nested object keys and escaped-key aliases, before enforcing the existing strict aggregate-only/privacy flags. Do not echo untrusted key or value strings in errors. Accepted canonical JSON and advisory-only/zero-authority fields remain unchanged.
