# ResoArc Sheet v0.7 QA 検証報告

日付: 2026-10-23
判定: 開発QA用 / 正式公開 NO-GO（中央統合管理のGO前）
製品: ResoArc Sheet

## 変更
- 値のみ貼り付け（ホーム、Ctrl+Shift+V）: 入力欄経由のTSV一括貼り付け、数値・文字列の型維持、最大1000セル、10万字以内、数式先頭=の拒否、結合セル・範囲外の拒否。
- FortuneSheetの自動型変換による先頭ゼロ消失を回避するため文字列貼り付けを明示的テキスト型に固定。文字列には ct=@ が必要となる場合があり、数値表示形式の維持は保証しない。フォント等の装飾は維持。
- 列幅／行高の入力ダイアログ（ホーム）とFortuneSheetのsetColumnWidth / setRowHeight APIを追加。変更内容を通常XLSX保存で出力。
- v0.6までの数式バー、F2、Ctrl+1、右クリック日本語ラベル、元構造保存モードと互換性監査を維持。

## 検証
- paste-values.test.mjs: TSVと改行/引用符の解析、先頭ゼロと数値精度、数式拒否、セル数上限の5項目に合格。
- paste-values-browser.mjs: A1から3行2列の日本語/数値/先頭ゼロ文字列を貼り付け、XLSX保存後のセル値と太字を検証。0エラー。
- cell-size-browser.mjs: B列幅230px、2行高55pxを設定しXLSX保存。ExcelJS再読込で列幅増加・行高増加、0エラーを検証。
- Nodeユニットテストは26/26合格。既存のXLSX編集と数式再計算（840・1840）、日本語右クリック13項目、実グラフXMLを維持する安全保存もv0.7ビルドで再試験合格。外部HTTPアクセス・JavaScriptエラーなし。
- CSV/JSON機能はv0.6で合格済み。v0.7で直接変更していない。

## 既知の制限
- 実際のExcelのCtrl+Shift+Vの動作と完全一致しない。専用入力欄への手動ペースト方式。
- 値貼り付けの文字列型を保証する代わり、数値書式が変更されることがある。
- 書式付きコピー/リッチクリップボード、F2の直接セル内編集、印刷プレビュー、オートフィルの完全互換は未完成。
- 元XLSXの高度な構造が全ケースで保たれる保証はない。既存の安全保存は列幅や行高変更を拒否。
- OSS依存関係の完全なSBOMと権利確認、複数ブラウザのQA、性能試験、公開審査が未完了。

公開: Codeberg/GitHubの正式main・resoarcサイトの配信環境は変更しない。オンラインにはQAブランチでのみ反映する。
