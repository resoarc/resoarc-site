# ResoArc Sheet v0.6 QA (2026-10-22)

**正式公開前の検証版です。ResoArc本番サイトには未公開です。**

## 起動（メインPC / Windows）
1. Node.js 20以上がインストールされていることを確認する（メインPCはNode.js 24を確認済み）。
2. `start-offline.cmd` をダブルクリックする。自動で Edge などのブラウザが `http://127.0.0.1:5174/` を開く。
3. 上部の「ファイル」タブから「開く」で .xlsx / .csv を選ぶ。JSONバックアップは同じタブの「復元」を使用。
4. 「ファイル」タブの「保存」または「CSV保存」で**新しいファイル**をダウンロードする。上書きはしない。
5. 編集中のバックアップには「ファイル」→「バックアップ」を使う。自動保存はない。

ZIPから展開して使う場合は、`dist/`、`serve.mjs`、`start-offline.cmd` を同じ階層に置く必要がある。Windows Defenderやセキュリティソフトの確認画面が出た場合は内容を確認すること。

## 開発
```powershell

```

開発モードは `http://127.0.0.1:5173/`。配布用画面を確認する場合は `node serve.mjs`。

## 機能
- Excel .xlsx 取込、セル編集、書式設定、基本関数、複数シート、別名保存
- 数式再計算とExcelの数値型維持（独自修正）
- CSV取込/保存、Windows CRLFファイルの整形
- ローカルJSON形式のバックアップ/復元、未保存警告、Ctrl+S / Ctrl+O
- Excel内の高度な機能の一部を事前検出し、互換性に関する警告を表示
- ログイン不要。ファイルデータはブラウザ内で処理され、ファイルをアップロードするサーバーを設けない構成

## 互換性と安全性
**Microsoft Excelと100%互換ではありません。** グラフ、図形、画像、ピボット、条件付き書式、名前定義、外部データ接続、印刷設定、VBA等は保存で失われたり変化したりする可能性があります。マクロ有効ブック(.xlsm)、旧形式(.xls)、バイナリ(.xlsb)、パスワード保護されたExcelは読み込み拒否。重要な帳票は必ず原本を保持し、コピーを編集して比較してください。

CSVは書式/型の定義を持たないため、CSVから読み込んだ数量は文字列扱いとなる場合があります。計算や会計に用いるときはExcel形式で入力値の型を確認してください。

Excelの数値型は元の.xlsx XMLに格納されている型を参照して復元しています。識別子（例: 0007）を単純な数字に変換しない設計です。ただしすべてのExcel機能・あらゆるブックの互換性は未検証です。

最大ファイルサイズは20MB。ブラウザ動作時に外部CDNやクラウド処理は不要ですが、OSの通信やブラウザ機能そのものを管理する仕組みではありません。

## v0.6 キーボード操作・書式ダイアログ

- **F2:** 選択中のセルを編集するため、ResoArcの数式バーへフォーカスを移動します。Excelのような「セルの中で直接編集するF2」とはまだ異なります。
- **Ctrl+1:** 日本語の「セルの書式設定」を開きます。表示形式（標準、数値、桁区切り、%、円、日付、文字列）、フォント、文字サイズ、太字、斜体、左右中央の配置に対応します。
- **ホーム → セルの書式:** ショートカットを使わずに同じ書式ダイアログを開けます。
- 入力欄を編集中はショートカットを横取りしません。Escで書式ダイアログを閉じます。
- 書式変更は通常の「保存」でXLSXへ出力できます。**安全保存はセルの書式変更には対応しないため、変更すると拒否します。**

現在未対応: F2のセル内編集、Ctrl+1の罫線・保護・すべてのExcel形式、数式候補の完全一致、OSネイティブのファイル関連付け。

- **ホーム:** Undo/Redo、太字/斜体/下線、フォント・サイズ・文字色・塗りつぶし、左右中央揃え、表示形式、内容クリア。
- **挿入:** 行・列・シートの追加。
- **数式:** 基本関数入力のショートカット。
- **表示:** 先頭行/先頭列の固定と解除。
- **ファイル:** 新規/開く/保存/安全保存/CSV/バックアップと復元。
- **名前ボックス:** A1, B2:D10 等を指定して移動（Enter）。
- **数式バー:** 選択セルの値・数式を表示し、Enterで編集。数式入力後の計算反映を検証。
- 右クリックの主要13項目に日本語ラベルを重ねて表示。クリック処理自体はFortuneSheetの標準メニューを使用し変更しません。**アクセシビリティや未翻訳メニューは引き続き改善予定**。
- 390px幅でページ自体の横はみ出しを防止。狭い画面のリボンは横スクロール式。

この画面はExcelと同じ商標・アイコン・レイアウトを複製するものではありません。機能の操作習慣を参考にしたResoArc独自UIです。
**未対応:** Excel全ショートカットや入力規則・データ分析・細かな貼り付け形式、Excel全体と完全一致する操作感は未実装です。

## v0.4 元のXLSXを残す「安全保存」

v0.4から、既存のXLSXを開いたときに **◇ 安全保存** が選べます。これは通常の「XLSX保存」とは別機能です。Excelの元ファイルを編集して上書きするのではなく、**読み込んだ原本のZIP/OOXMLを複製し、変更した既存セルの値・既存数式だけをXMLに反映する方式**です。未編集のグラフ・画像・描画リレーション・印刷設定・条件付き書式の関連ファイルを維持します。保存後のファイル名は `元ファイル名.preserved.xlsx` です。

安全保存の制限:
- 既存の .xlsx のみ。CSVやJSONから起動したブックでは利用できません。
- **元から存在するセルの値・文字列・数式の変更**のみ。新規セル、セル削除、行列の追加や移動、シート設定・幅・書式の変更は拒否します。
- 共有数式・配列数式、ハイパーリンク付きセル、シート保護、Excelテーブル、マクロ付き・電子署名付きブックなどは必要に応じて拒否します。
- 一度に500セルまで。大きなXMLや圧縮展開リスクのあるブックも拒否します。
- 編集前後の内部表計算データを比較し、変更対象の座標だけをパッチします。編集しなかった数式の既存キャッシュ値が古いことがあるため、Excelで開いたときに再計算するよう `fullCalcOnLoad=1` を指定します。
- 元ファイルは常に保持し、通常のXLSX再生成へ自動的には切り替えません。
- これは「Excelを完全再現する」機能ではありません。元ファイルの複雑な相互参照により互換性問題が残る可能性があります。

QAでは、ブラウザからExcelを読み込み、B2値を変更して安全保存し、画像・条件付き書式・複数シートの保持を検証しました。さらに棒グラフのある実際のXLSXを保存し、OpenPyXLによってグラフ1個、セル値、数式、枠固定が保持されていることを確認しました。**すべてのグラフの再描画、VBA、ピボット更新まで保証しません。**

## v0.3 保存前の互換性監査

既存のXLSXを編集して保存する場合、元ファイルと出力予定のXLSX内部XMLを比較して、グラフ・画像・ピボット・Excelテーブル・数式・条件付き書式・入力規則・結合セル・固定ウィンドウ・外部リンクなどについて、**構造要素の件数が減少していないか**を検査します。既知の高リスク機能が含まれている場合や欠落を検出した場合は、ダウンロード前に確認ダイアログを表示します。キャンセルした場合は**保存・ダウンロードを行いません**。

互換性チェックは**件数比較**であり、セル書式の色・フォント、式の意味、画像内容や内部XMLの完全一致を保証しません。警告がない場合もExcelと100%互換ではありません。監査後の「互換性監査JSON」ボタンで、セル値を含まない構造差分レポートを保存できます。

CSV保存は複数シート・数式・セル書式を保持しないため、保存前に警告します。
